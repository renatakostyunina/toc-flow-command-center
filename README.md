# TOC-Flow Command Center

Учебный pet-проект по бизнес- и системному анализу: единое аналитическое решение (витрина данных, 5 дашбордов, система алертов) для производственного завода на основе **Теории ограничений (TOC)**.

> Проект учебный. Кейс построен на сюжете романа Э. Голдратта «Цель»: заказчик «Завод Алекса» и все персонажи вымышленные.

## Контекст и проблема

**Заказчик:** завод Алекса.
**Проблема:** управленческие решения принимаются реактивно, а не проактивно: «мы не управляем, мы реагируем».

Главное управленческое ограничение здесь не станок, а метрики, не отвечающие цели бизнеса. Завод оценивают по загрузке всех ресурсов и эффективности каждого станка (OEE). Из-за этого материалы запускают как можно раньше, растёт незавершённое производство (WIP), а узкое место скрывается за горами запасов.

## Моя роль

Бизнес-/системный аналитик: анализ стейкхолдеров и их болей, сбор и формализация требований, AS-IS и TO-BE процесса, проектирование метрик и дашбордов, подготовка передачи в разработку.

## Ключевые решения

- **Узкое место определяется автоматически** по максимальному времени ожидания перед станком за последние 60 минут.
- **Управление по DBR** («Барабан — Буфер — Верёвка»): запуск материалов подчинён ритму узкого места, система выдаёт рекомендацию по количеству запуска.
- **Глобальные метрики T, I, OE** (Throughput, Inventory, Operating Expense) вместо локальной загрузки станков.
- **Единая витрина «Поток заказа»**: временная отметка каждой детали на каждом станке как единый источник данных.
- **Ролевые экраны** для директора, производственного менеджера, плановика, оператора, кладовщика, наладчика и бухгалтера.
